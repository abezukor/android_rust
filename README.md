This repository contains various utilities for working with android system APIs from rust. The [Android NDK only supports a limited subset of APIs](https://developer.android.com/ndk/guides/stable_apis), so to implement more things you must use jni to interop with java/kotlin code.

Libraries were initially developed for use within the [Matic App](https://play.google.com/store/apps/details?id=com.maticrobots.maticapp)
